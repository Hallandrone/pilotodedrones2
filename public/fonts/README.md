# Font Download Instructions

Due to download connection issues, please manually download these fonts:

## Required Fonts

### 1. Euphorigenic (para nombre del estudiante)
- Download from: https://www.1001fonts.com/euphorigenic-font.html
- Save as: `public/fonts/Euphorigenic.ttf`

### 2. Croogla 4F (para nombre del curso)
- Download from: https://www.dafontdl.com/croogla-4f-font/
- Save as: `public/fonts/Croogla4F.ttf`

### 3. Montserrat Light Italic (para fecha y ciudad)
- Download from: https://fonts.google.com/specimen/Montserrat
- Click "Download family"
- Extract and copy `Montserrat-LightItalic.ttf` to `public/fonts/`

### 4. Open Sans Regular (para textos secundarios)
- Download from: https://fonts.google.com/specimen/Open+Sans
- Click "Download family"
- Extract and copy `OpenSans-Regular.ttf` to `public/fonts/`
